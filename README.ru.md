# dsh-image-studio

Вкладка **«Изображения»** для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): одна страница, где
можно генерировать картинки через [fal.ai](https://fal.ai), листать всё, что вы когда-либо нагенерировали, выбирать
лучший кадр и тут же отдавать его в Kling как image-to-video.

```text
Изображения
┌──────────────────────────────────────────────────────────────────────┐
│ Опишите изображение…                                                 │
│  Модель: GPT Image 2 ▾   Формат: 9:16 ▾   Вариантов: 4 ▾  [Создать]  │
├──────────────────────────────────────────────────────────────────────┤
│  Галерея | Шаблоны          Все · Картинки · Видео · Избранное       │
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐                        │
│  │  🖼     │ │  🖼     │ │  🎬 5s │ │  🖼     │  клик → просмотр       │
│  └────────┘ └────────┘ └────────┘ └────────┘  → «Оживить в Kling»    │
└──────────────────────────────────────────────────────────────────────┘
```

## Что внутри

- **Настоящая страница, а не сообщение в чате.** В левом сайдбаре появляется пункт **«Изображения»**: сверху промпт,
  выбор модели, формата и количества вариантов (до 8), снизу — галерея.
- **Под капотом fal.ai.** Три семейства text-to-image подключены с теми именами полей, которые объявлены в OpenAPI
  самого fal: `fal-ai/flux-2/klein/9b` (быстро и дешево — перебирать варианты), `openai/gpt-image-2` (качество, текст
  на картинке), `fal-ai/nano-banana-2` (Gemini, работа с референсами, 0.5K–4K). Любой другой slug fal со слэшем
  принимается как кастомный endpoint.
- **Всё, что вы сгенерировали, остаётся на месте.** Результаты ложатся в папку студии на диске, рядом — индекс. Поэтому
  просмотр ничего не стоит, переживает перезапуск и работает, даже когда провайдер недоступен. Есть избранное, поиск по
  промпту и фильтры по типу.
- **Просмотрщик, которым реально пользуешься.** Кадр на весь экран, скачивание оригинала, копирование промпта, отметка
  «в избранное» и кнопка **«Оживить в Kling»** — та самая картинка уходит в Kling v3 Pro image-to-video с вашим
  описанием движения и выбранной длительностью.
- **Шаблоны.** Восемь стартовых промптов (продукт на подиуме, лайфстайл, UGC-селфи, флэтлей, до/после, сезон, лист
  персонажа, фуд-клоуз) на русском и английском. Шаблон только заполняет поле промпта — деньги тратятся лишь после
  нажатия «Сгенерировать».
- **Два языка интерфейса** — русский и английский, по языку интерфейса.
- **Ключ не покидает хранилище.** Карточка настроек пишет ключ fal через credential-seam харнесса: хост никогда не
  возвращает значение на страницу и никогда не сохраняет секрет в конфигурацию.

## Установка

### Через страницу плагинов (рекомендуется)

1. Откройте **Плагины → Добавить плагин**.
2. Вставьте имя пакета (когда он опубликован) либо абсолютный путь к этой папке:

   ```text
   dsh-image-studio
   C:\Users\you\Documents\deepseek-harness\dsh-image-studio
   ```

3. Установите; если плагин попросит перезапуск — перезапустите харнесс.

### Из терминала

```sh
dsh plugin --profile web add dsh-image-studio      # веб-профиль
dsh plugin --profile desktop add dsh-image-studio  # только когда DSH Desktop полностью закрыт
```

Профиль `desktop` принадлежит приложению DSH Desktop: пока оно запущено, терминальное управление отклоняется — там
используйте **Плагины → Добавить плагин**. После установки в сайдбаре появится пункт **«Изображения»**.

## Где хранится ключ

Ключ — это *ссылка* на credential, а не значение в конфигурации. Ссылка по умолчанию — `FAL_API_KEY`, порядок поиска
значения — родной для харнесса:

1. окружение запуска (`FAL_API_KEY=… dsh`) — из приложения не перезаписывается;
2. хранилище ключей `~/.dsh/.credentials.yaml`:

   ```yaml
   version: 1
   refs:
     FAL_API_KEY: <key_id>:<key_secret>
   ```

3. `<рабочая папка>/.env`, затем `~/.dsh/.env`.

Проще всего — карточка **Настройки → Плагины → Изображения (fal.ai)**: вставьте `key_id:key_secret` (всю строку из
fal.ai → Keys) и нажмите «Сохранить». Карточка показывает только факт наличия ключа и источник — не значение. Следующая
генерация сразу использует новый ключ, перезапуск не нужен.

Имя ссылки можно поменять в конфигурации строки (`falKeyRef`) — удобно, если на машине ключи лежат под другим именем.

## Где лежат файлы

```text
<DSH_HOME>/image-studio/
  gallery.json     индекс: одна запись на картинку или видео
  config.json      несекретные значения по умолчанию (модель, формат, количество)
  files/<id>.png   сами файлы, имя — сгенерированный id
```

`<DSH_HOME>` — это `$DSH_HOME` или `~/.dsh`. Переменная `DSH_IMAGE_STUDIO_HOME` переносит студию в другое место —
например, на большой диск или в отдельный бэкап. Ничего из этой папки не отдаётся другой машине: `/api/image-studio/file`
отвечает только локальным запросам, а путь собирается из проверенного id.

## Конфигурация

Настройки строки в патче профиля (`~/.dsh/profiles/<профиль>/cordis.patch.yml`):

| Ключ | По умолчанию | Значение |
|---|---|---|
| `falKeyRef` | `FAL_API_KEY` | Ссылка на credential с ключом fal. |
| `defaultModel` | `fal-ai/flux-2/klein/9b` | Модель, выбранная на странице. |
| `defaultAspect` | `1:1` | Формат по умолчанию. |
| `defaultCount` | `1` | Количество вариантов по умолчанию. |
| `imageTimeoutMs` | `240000` | Бюджет одной задачи на картинку. |
| `videoTimeoutMs` | `900000` | Бюджет одной задачи на видео; Kling рендерит минутами. |

## HTTP-поверхность

Всё, что делает страница, идёт через собственные локальные роуты плагина — чтобы браузерная половина никогда не
обращалась напрямую ни к провайдеру, ни к ключу, ни к путям на диске.

| Роут | Назначение |
|---|---|
| `GET /state` | Каталог, значения по умолчанию, статус ключа, счётчики, путь студии |
| `GET /gallery?kind=&q=&favorite=` | Отфильтрованный индекс |
| `GET /file?id=` | Байты медиа для одной записи |
| `POST /credentials` | Сохранить или удалить ключ fal (только запись) |
| `POST /config` | Несекретные значения по умолчанию |
| `POST /generate`, `POST /video` | Поставить задачу в очередь, ответ `202` с задачей |
| `GET /job?id=` | Статус, позиция в очереди, готовые записи |
| `POST /favorite`, `POST /delete` | Работа с галереей |

Каждый роут отказывает всему, что пришло не с loopback и не с локального origin, тело запроса ограничено 256 КБ, а
медиа читается только из путей, собранных из проверенного id.

## Совместимость

| Пакет | Версия |
|---|---|
| `dsh-image-studio` | 0.1.0 |
| Ядро DSH | `0.2.0-rc.2`, `0.2.0-rc.1` (см. `compatibility.json`) |
| Node | `^22.19.0 \|\| >=24.0.0` |

Windows и macOS поддерживаются одинаково: нет платформенного кода, вызовов шелла, нативных модулей и шага сборки —
браузерная половина это обычный скрипт, который харнесс загружает сам.

всегда.

## Известные ограничения

- **Только fal.ai.** Провайдер один; другой шлюз — это ещё один модуль рядом с `lib/fal.js`.
- **Пока нет входа с референсом.** Image-to-image и консистентность персонажа на странице не выведены, хотя
  соответствующие endpoint'ы у fal есть.
- **Задачи живут в памяти.** Генерация переживает перезагрузку страницы, но не перезапуск харнесса; уже записанные
  файлы остаются в любом случае.
- **Галерея локальная.** Это папка, а не сервис синхронизации.
- **Модель не видит видео.** В контент-модели харнесса нет видеоблока, поэтому модель узнаёт путь к файлу. Картинки
  возвращает в переписку тот плагин, который их генерирует, а не эта страница.

## Приватность

Плагин общается только с fal.ai. Промпты, медиа и ключ остаются на машине; ключ читается из хранилища харнесса на
каждый вызов и никогда не логируется, не возвращается и не пишется в файлы конфигурации.
